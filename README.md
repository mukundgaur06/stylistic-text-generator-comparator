# Stylistic Text Generator Comparator

[![Built with askThili](https://ask.thili.ai/api/v1/public/projects/y999xh39zr/badge.svg)](https://ask.thili.ai/b/y999xh39zr)

This project creates a 'Stylistic Text Generator Comparator' for sports journalists. It demonstrates how to fine-tune both an N-gram model and a LoRA-adapted Large Language Model (LLM) on a specific sports commentary style. The tool allows for a direct comparison of the text generated by each model, highlighting their respective strengths and weaknesses in capturing stylistic nuances.

## What you are building

**Goal.** You will have built a tool that fine-tunes a pre-trained language model with LoRA and an N-gram model on sports commentary, then compares their text generation quality.

**Done when.** The project is complete when you can fine-tune both an N-gram model and a LoRA-adapted LLM on a custom sports commentary corpus, generate text from both, and present a qualitative comparison interface for the generated outputs.

## Run it

You need Python 3.12 and git.

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # then choose a model; see the comments inside
python -m app.cli hello
pytest
```

Your work goes in `app/core.py` (one stub per milestone) and `tests/test_core.py`. The first tests pass already; they
check the plumbing.

## Settings and secrets

Model settings live in `.env`, which is ignored by git. **Never commit `.env` or paste a key into code.** If a key ever
reaches GitHub, treat it as leaked and make a new one.
